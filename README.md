# زیست هوشمند (IB1)

پلتفرم فارسی و موبایل‌اول برای ثبت و پیگیری سلامت، آموزش علمی و گزارش‌های هوشمند با بازبینی پزشکی.

**وب‌سایت:** https://ib1.ir

## قابلیت‌ها
- پروفایل و سوابق سلامت، اندازه‌گیری‌ها و روند
- آناتومی تعاملی و پرسشنامه‌ها
- ۱۴ حوزهٔ سلامت (روشن/خاموش‌شدنی)
- مرکز آموزش، ماشین‌حساب BMI و دموی مغز
- دندانپزشکی و طرح لبخند، پزشکان، کتابخانهٔ کتاب
- پنل مدیریت کامل

## ایمنی و حریم خصوصی
محتوا آموزشی است و جایگزین پزشک نیست. داده‌ها در اختیار کاربر است.

## فناوری
Node.js، TypeScript، Preact، MariaDB.
